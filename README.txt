HARSHIT TYAGI — PERSONAL PORTFOLIO
===================================

RUN LOCALLY
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open it in your browser.

OPTIONAL LOCAL SERVER
If Python is installed, open a terminal in this folder and run:
    python -m http.server 8000
Then visit:
    http://localhost:8000

UPLOAD TO A WEB SERVER
Upload index.html, style.css, script.js, and the assets/ folder together.
Keep the folder structure intact. The site is static and does not require a backend.

CUSTOMIZE BEFORE PUBLISHING
- Replace assets/profile.jpg with another portrait if you wish (keep the same filename).
- Check the email and LinkedIn URL in index.html.
- Project summaries are starter descriptions based on project names. Update them with accurate features and each project's actual repository URL.
- The skill list is a broad starter list based on the requested technologies; edit it to reflect your current proficiency.
- The contact CTA opens an email app using mailto; it does not store submissions in a database.
- Google Fonts are loaded online. A system-font fallback is included if offline.

Files:
index.html  — website structure and content
style.css   — responsive visual design and animations
script.js   — mobile menu, typing effect, scroll reveal, active navigation
assets/profile.jpg — provided profile photo
